Generate multiresolution peaks asynchronously and virtualize long timelines/many clips.

## Acceptance

Zoom/scroll remain responsive on target stress project and cache invalidation is correct.

## Notes

- 2026-08-19: the peak cache is multiresolution — `crates/jutsu-audio-project/src/waveform.rs`
  builds coarser levels by folding the level below, so building them all costs about what
  building the base level did. `CachedWaveform::level_for` picks the level with roughly one peak
  per pixel, and the timeline draws from that rather than folding thousands of base peaks per
  column when zoomed out.
- 2026-08-19: invalidation is by content fingerprint (unchanged) plus a cache format version. A
  cache written before the levels existed is refused on load, which is what makes the worker
  rebuild it; a half-used old cache would have drawn a flat line.
- 2026-08-19: viewport work was already in place — lanes and clips outside the visible rectangle
  are culled before painting, and only the pixel columns inside the viewport are drawn.
