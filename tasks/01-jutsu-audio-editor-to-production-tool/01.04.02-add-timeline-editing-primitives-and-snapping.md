Implement range selection, copy/paste/duplicate, ripple/non-ripple delete, slip, fades, crossfades, grid/marker snapping, and command batching.

## Acceptance

Edge cases at zero/end/overlap are covered and undo is one logical step.

## Notes

- 2026-08-19: primitives live in `jutsu-audio-commands::edits` — split, duplicate, ripple/plain
  delete, slip, fades, cross-fade, paste. Each returns one command batch, which is what makes
  undo one logical step; the GUI buttons and the CLI operations both call them rather than
  building commands by hand.
- 2026-08-19: fades are clip parameters the renderer applies, clamped to the clip in both the
  command engine and the mix, so a stored fade can never exceed the material it shapes.
- 2026-08-19: multi-clip range selection is not in the GUI yet — every primitive already takes a
  slice of clip IDs, so the selection model is the only thing left to grow. Marker snapping waits
  on markers, which are 01.04.04; grid snapping was already in place.
