## Acceptance

Fault-injection tests demonstrate no silent project loss.

## Notes

- 2026-08-19: Autosave keeps the previous generation (`.autosave.1`) and recovery falls back to
  it when the newest will not read; a clip whose source will not decode now plays silence with a
  `SourceUnreadable` diagnostic instead of failing the whole mix, and `export_wav` returns those
  diagnostics; added `jutsu_audio_project::report` plus the `diagnose` CLI operation, which works
  on a project that will not open and never writes to it. `tests/fault_injection.rs` covers power
  loss, a refused write, a newer-schema file, migration backups, unknown extensions round-tripping
  untouched, a damaged sample, and reporting on a corrupt project. Rules written up in
  `docs/design/crash-recovery-and-compatibility.md`.
