Represent synth events/clips in project and expose creation, audition, note/event edits, and typed parameters in both interfaces.

## Acceptance

Unknown or invalid parameters return registry-derived diagnostics.

## Notes

- 2026-08-19: a synth clip is an ordinary clip whose asset is `AudioAssetSource::Synth`, plus the
  notes on the clip itself. Both are additive and skipped when empty, so existing projects and the
  schema version are untouched.
- 2026-08-19: the mix renders synth clips through the registry (`mix_project` now takes
  `&ExtensionRegistries`), so playback, preview and export all play the same notes. Every clip gets
  a fresh, reset instance — a mix is the same however often it is rendered.
- 2026-08-19: parameter validation lives at the surfaces, in `src/cli_synth.rs` and the GUI's
  apply path, because the registry is what knows. The command engine stays extension-agnostic and
  the caller gets an error naming the parameter and listing what is available.
- 2026-08-19: `src/synth_panel.rs` builds the inspector's synth section from the descriptor, so a
  synth registered later gets an editor without touching the GUI.
