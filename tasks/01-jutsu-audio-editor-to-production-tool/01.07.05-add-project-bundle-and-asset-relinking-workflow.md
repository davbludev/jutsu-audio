Package project plus used assets/presets and relink moved/missing files by fingerprint.

## Acceptance

Bundle opens on another machine without absolute paths and reports unresolved assets.

## Notes

- 2026-08-19: a bundle is a directory — project, `assets/`, `presets/` — with every path inside it
  rewritten to be relative to it. `absolute_asset_paths` is what "opens on another machine" is
  actually checked with, and it judges the path as text rather than through the host's rules, so a
  Windows build still spots a POSIX-absolute path.
- 2026-08-19: relinking matches on the content fingerprint, because that is what identifies audio;
  a renamed or moved file is found, and an unrelated file of the same name is not. The repoint goes
  through a `RelinkAsset` command, so it undoes and reaches an open editor like any other edit.
- 2026-08-19: both report rather than hide. A bundle with unreadable audio is still written and
  says what is missing; a relink that finds nothing says which assets are still unresolved.
