Add narrow reusable generators for impact, explosion, laser, pickup, and ambience using registered synth/effect building blocks.

## Acceptance

Each supports seed and useful bounded parameters, presets, preview, and regeneration.

## Notes

- 2026-08-19: five generators, one file each under
  `crates/jutsu-audio-extensions/src/generators/` — impact, explosion, laser, pickup, ambience —
  over a shared `dsp.rs` (one-pole filter, exponential decay, phase helpers, normalisation).
  Each is narrow on purpose: layering three clips beats one generator with thirty knobs.
- 2026-08-19: `ParameterDescriptor` gained optional `minimum`/`maximum`, and the registry refuses
  values outside them. That is what "bounded parameters" means here — the bound is discoverable
  from the descriptor and enforced before a generator body ever sees a value.
- 2026-08-19: presets are named parameter sets on the factory, and a test renders every one of
  them, so a preset can never name a parameter the generator does not have.
- 2026-08-19: preview and regeneration ride on what already exists — a generated clip is rendered
  by the mix from its provenance, so previewing is playing and regenerating is changing the seed.
  The CLI surface for both is 01.05.05.
