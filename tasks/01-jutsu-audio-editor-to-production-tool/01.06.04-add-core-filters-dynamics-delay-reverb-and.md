Implement production-usable built-ins with bounded parameters and presets.

## Acceptance

DSP tests cover stability, silence, clipping/NaN prevention, channel handling, and deterministic offline output.

## Notes

- 2026-08-19: five built-ins, one file each under `crates/jutsu-audio-extensions/src/effects/` —
  low-pass, high-pass, compressor, delay and reverb — over shared pieces in `mod.rs` (a delay line
  sized at `prepare`, decibel conversion, and `safe`, which every effect ends with so a NaN or an
  overshoot can never reach the mixer).
- 2026-08-19: bounds are what keep them stable. Feedback is capped below one in both the delay and
  the reverb, filter cutoffs are clamped below Nyquist, and a test runs every effect at both ends
  of every declared range for eight passes to prove none of that is theoretical.
- 2026-08-19: presets moved to one shared `Preset` type used by generators and effects alike, and
  every preset is instantiated in tests, so a preset can never name a parameter its effect lacks.
- 2026-08-19: the offline lock wait went from 2 to 10 seconds after a concurrency test flaked on a
  loaded machine — two seconds is not long for a contended save, and the failure mode was a
  refused edit rather than a wrong one.
