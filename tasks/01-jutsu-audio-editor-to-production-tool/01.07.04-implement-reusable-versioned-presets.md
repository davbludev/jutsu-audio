Support synth, effect, chain, generator, and instrument presets with stable type IDs, schema versions, tags, import/export, and migration.

## Acceptance

User presets never mutate built-ins and incompatibilities are reported.

## Notes

- 2026-08-19: `crates/jutsu-audio-project/src/presets.rs` is the library: one JSON file per preset
  under `<library>/<kind>/<id>.json`, so a preset can be copied, mailed or committed on its own.
  Built-ins stay in code, which is why saving can never overwrite one — the split is structural,
  not a rule someone has to remember.
- 2026-08-19: five kinds — synth, effect, chain, generator, instrument. A chain preset holds no
  entity IDs, so applying it mints fresh inserts for the project it lands in.
- 2026-08-19: every preset carries the format's schema version and the state version of what it
  configures. A newer format is refused with its reason; a moved state version is applied and
  reported, because it usually still means what it said. `migrate` is a hook with nothing to do
  yet, so a later version has an obvious place to land.
