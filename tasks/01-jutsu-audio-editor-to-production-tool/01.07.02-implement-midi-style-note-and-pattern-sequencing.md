Add note clips, patterns, quantization, velocity, humanization with seed, looping, and non-destructive transforms.

## Acceptance

Edits are command-based, deterministic where randomized, and export correctly.

## Notes

- 2026-08-19: patterns are project-level note sequences a clip can point at, resolved by
  `Clip::resolved_notes` — which is also where looping happens, so playback, export and transforms
  all see one flat list. A clip's own notes win over its pattern, so a one-off variation needs no
  unlinking.
- 2026-08-19: transforms live in `crates/jutsu-audio-commands/src/notes.rs`: quantise (against the
  tempo map), transpose, scale velocity, humanise and loop. Each returns one batch, so each is one
  undo step and reaches an attached session.
- 2026-08-19: humanisation is seeded with a specified splitmix-style derivation, two streams per
  note so timing and velocity are independent. The same seed gives the same result — which is what
  makes a humanised part safe to commit.
- 2026-08-19: removing a pattern unlinks the clips that played it in the same batch, so validation
  can treat a dangling `pattern_id` as the error it is.
