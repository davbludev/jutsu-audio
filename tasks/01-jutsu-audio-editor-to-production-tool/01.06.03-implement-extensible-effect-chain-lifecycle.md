Support ordered inserts, bypass, wet/dry, state, latency/tail reporting, and registry-based instantiation.

## Acceptance

Missing/version-mismatched effects degrade safely with actionable diagnostics.

## Notes

- 2026-08-19: an insert is `EffectInsert` on a track or bus — type, state version, parameters,
  enabled, wet — and chains are ordered lists, because order is what a chain *is*. Both fields are
  additive and omitted when empty.
- 2026-08-19: `Effect` gained `prepare` / `reset` / `latency_frames` / `tail_frames`, and each
  channel of a stereo strip gets its own instance so a filter's state cannot leak across it.
  Inserts run before the strip: a fader should change how loud the processed signal is, not how
  hard it hits the processing.
- 2026-08-19: degradation is the point of `crates/jutsu-audio-engine/src/effects.rs`. A missing
  extension, a refused parameter set or a moved state version never fails the mix — the audio
  passes through (or plays as saved) and `MixOutput::diagnostics` says what happened and what was
  done instead.
- 2026-08-19: `MixOutput::timing` reports latency summed along the path and the longest tail.
  Reported, not compensated: an offline render lays everything on one timeline, and a caller
  aligning against live playback needs the numbers rather than a silent shift.
- 2026-08-19: commands `AddEffect`, `RemoveEffect`, `MoveEffect`, `SetEffectEnabled`,
  `SetEffectWet`, `SetEffectParameters`, each with an inverse. Built-in effects are 01.06.04; the
  lifecycle is tested against a mock so it does not depend on any particular DSP.
