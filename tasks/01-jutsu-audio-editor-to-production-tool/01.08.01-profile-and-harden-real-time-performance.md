Define latency/CPU/memory targets; stress voices, tracks, effects, seeks, live edits, and long sessions.

## Acceptance

Benchmarks expose regressions; callback remains allocation/lock/I/O safe under supported load.

## Notes

- 2026-08-19: the callback's contract is now checked rather than trusted.
  `crates/jutsu-audio-engine/tests/realtime_safety.rs` installs a counting global allocator and
  fails if a render allocates once — across the verbatim path, the conversion path, loop wraps,
  seeks, a mix published mid-playback, and the underrun path.
- 2026-08-19: the counter is per thread. A global one was counting other tests' allocations,
  because `cargo test` runs them in parallel — a good reminder that a measurement needs a scope.
- 2026-08-19: `cargo bench -p jutsu-audio-engine` runs a stress harness that prints how fast each
  project shape mixes against real time. Printed, not asserted: timing on a shared machine is not
  a pass/fail signal, and the guarantees that matter are the ones tests hold.
- 2026-08-19: budgets and the split between guaranteed and measured are written up in
  `docs/design/performance-budgets.md`.
