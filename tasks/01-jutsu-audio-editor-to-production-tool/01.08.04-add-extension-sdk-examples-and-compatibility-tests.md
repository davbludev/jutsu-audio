Provide minimal third-party synth, effect, and generator examples plus registry conformance tests and version policy.

## Acceptance

Extensions build outside core crates and failures cannot corrupt project state.

## Notes

- 2026-08-19: `examples/pocket-extensions` is a third-party pack (synth, effect, generator) built
  outside the core crates against the published surface only. `jutsu_audio_extensions::conformance`
  holds any extension to the rules the built-ins keep — defaults, declared ranges, determinism,
  reset, finite output within full scale — and is run over every built-in and over the pack. A
  clip naming an extension this build lacks now plays silence with an `ExtensionUnavailable`
  diagnostic instead of failing the mix, so a missing pack cannot stop a project opening,
  editing, saving or exporting. Version policy and the trait rules: `docs/extension-sdk.md`.
