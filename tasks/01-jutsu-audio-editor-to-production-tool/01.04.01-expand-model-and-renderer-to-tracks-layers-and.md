Support ordered tracks/layers, multiple overlapping clips, mute/solo, per-clip gain/pan, and deterministic summing.

## Acceptance

GUI, CLI, playback, save, and export share identical semantics.

## Notes

- 2026-08-19: summing moved into `jutsu-audio-engine::mixdown`. The GUI worker and the CLI export
  both call `mix_project` now — the CLI had its own summing loop, which is exactly the drift this
  removes. Track order, then layer order, then clip order is the summing order, so a mix is
  reproducible from the file.
- 2026-08-19: new commands `AddTrack`, `RemoveTrack`, `AddLayer`, `RemoveLayer`, `SetTrackMute`,
  `SetTrackSolo`, `SetClipPan`, each with an inverse. Reached from the GUI (track header M/S
  chips, "+ Track" / "+ Lane") and from the CLI, which routes them through the session like any
  other edit.
- 2026-08-19: pan is a square-root law normalised so centre stays unity in both channels; hard
  panning reaches +3 dB rather than re-levelling every existing project by -3 dB.
