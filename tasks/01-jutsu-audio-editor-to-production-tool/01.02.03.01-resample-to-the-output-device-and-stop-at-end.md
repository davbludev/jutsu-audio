Playback copied snapshot samples straight into the device buffer, so anything whose rate or
channel count differed from the default output device played at the wrong speed or not at all.

## Objective

`SystemAudioOutput::open_default` opened the device's default configuration, but
`PlaybackRenderer::render` wrote the snapshot's interleaved samples into that buffer verbatim.
A 48 kHz file on a 44.1 kHz device played 8.8% fast and sharp; a mono file on a stereo device
played at double speed with garbage stereo; a channel count that did not divide the buffer
length produced silence and an ever-climbing underrun counter.

Separately, once the read position reached the end of the snapshot the renderer neither
stopped nor advanced: it incremented the underrun counter on every callback forever, so `xrun`
was meaningless after the first playthrough.

## Acceptance

The renderer is built from the real device format and converts onto it: linear interpolation on
the time axis, `channel % source_channels` fan-out on the channel axis, and a straight average
when folding down to mono. When rate and channel count already match, the sample path stays a
verbatim copy so real-time output remains bit-identical to `OfflineExporter` and the existing
parity test still holds. Running out of material stops the transport and rewinds to zero
instead of reporting underruns; underruns now mean only genuine starvation. The audio callback
still performs no allocation, locking, or I/O.

## Notes

- 2026-08-19 — `PlaybackRenderer::new` now takes the output sample rate and channel count, and
  `SystemAudioOutput::open_default` takes the snapshot and transport readers so it can build the
  renderer from the device configuration it just opened; the renderer can no longer be
  constructed against a format it will not receive. Sub-frame phase is carried between callbacks
  in the renderer itself and reset whenever the transport position moves underneath it, so seek
  and stop do not smear. Added a real peak meter: the callback publishes the block peak into a
  new atomic on the shared transport state, which is what the status bar reads. New tests cover
  mono fan-out, stereo fold-down, half-rate and double-rate conversion, end-of-material stop,
  and starvation underruns. `cargo quality` passes.
