Export answers with a sample rate, a channel count and a frame count. A game audio pipeline
needs more than that, and none of it is exotic:

- integrated loudness and true peak in the report, so a delivery target is a number rather than
  an opinion;
- stems, one file per track or bus, from a single render;
- the project's loop region written into the WAV as a `smpl` chunk, so the loop survives the
  file leaving the editor;
- round-robin variations of a generated one-shot, so a repeated sound is not the same sound.

## Acceptance

The report carries LUFS and true peak measured against published test signals; stems sum back to
the master render; a written loop point reads back; a variation set is reproducible from its
seeds.
