Five effects, each with one or two knobs, is a palette for repairing a sound rather than
shaping one. Add: a parametric EQ with bands that have a frequency, gain and Q; a saturator; a
chorus with real stereo width; a true peak limiter for the master; and a delay that can be
given a note division instead of milliseconds, resolved against the project tempo where the
tempo is known.

Stereo width needs each channel's instance to know which channel it is, which the chain does not
tell it today.

## Acceptance

Every new effect is registered, conformance-tested, deterministic and safe at any declared
parameter value; the tempo-synced delay follows a tempo change.
