Record command inverses/history across GUI and CLI session edits, expose dirty/save state, and recover autosaves after crashes.

## Acceptance

Undo ordering is defined for external edits and recovery never replaces original silently.

## Notes

- 2026-08-19: history lives in `jutsu-audio-commands` (`history.rs`): a batch is inverted against
  the state it is applied to, and undo replays that inverse through the same engine, so there is
  still one mutation path. GUI and session edits share one chronological stack, which is the
  defined ordering for external edits.
- 2026-08-19: autosave is a `.autosave` sidecar written by `jutsu-audio-project::autosave` and
  removed by a successful save. Opening a project that has one shows `src/recovery.rs`, which
  loads the recovered work into the editor only on request and never rewrites the file itself.
