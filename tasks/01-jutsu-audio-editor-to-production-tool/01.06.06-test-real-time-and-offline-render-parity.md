## Notes

- 2026-08-19: `crates/jutsu-audio-engine/tests/render_parity.rs` builds one reference project that
  spans routing, automation, a sample clip, a synth clip, a generated clip and effects on both a
  track and a bus, then compares the device path against the exported file.
- 2026-08-19: the tolerance is *exact* when the device format matches the mix — there is one
  snapshot and the verbatim path copies it — and conversion is documented as a playback
  convenience with no export obligation. Written up in
  `docs/design/render-parity-and-tolerances.md`.
- 2026-08-19: tail and latency are reported rather than compensated, and an export covers the
  timeline and not the tail beyond it. Both are asserted, so the behaviour cannot drift into
  something surprising without a test saying so.
